the Ruflo thesis

A raw model is talented but unstructured. Ruflo is the execution layer around Claude Code and Codex — tools, memory, loops, sandboxes, and controls — so agents don't just run, they collaborate.

  • Tools — hundreds of MCP capabilities, on tap.
  • Memory — recall across tasks and sessions.
  • Loops & sandboxes — retry, isolate, contain.
  • Controls — routing, consensus, guardrails.
One command

npx ruflo init gives Claude Code a nervous system — agents self-organize, learn, and remember. You keep writing code; Ruflo handles the coordination.

04.2 Getting started

One command, then use Claude Code normally

  • Interactive wizard — runs identically on every platform.
  • Windows-friendly — the npx line works in PowerShell & cmd.
  • MCP in one line — register Ruflo as a Claude Code server.
# interactive setup wizard
npx ruflo@latest init wizard

# or one-line (POSIX shells)
curl -fsSL .../install.sh | bash

# add Ruflo as an MCP server
claude mcp add ruflo -- \
  npx ruflo@latest mcp start
